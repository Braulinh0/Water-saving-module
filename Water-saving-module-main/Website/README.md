# EcoMonitor 🌱

Sistema de monitoreo inteligente para ahorro de agua.

## Funciones
- Medición de humedad del suelo
- Temperatura en tiempo real
- Recomendación con IA
- Registro manual de riego

## Tecnologías
- HTML
- CSS
- JavaScript
- TailwindCSS
